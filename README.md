## Treino de JDBC
---

Projeto de estudo e prática do JDBC (Java Database Connectivity), utilizado para treinar conceitos de conexão, manipulação e persistência de dados em um banco MySQL a partir de aplicações Java.

Repositório: gpego1/treino-de-jdbc

---

## 📋 Sobre o projeto

Este repositório reúne exercícios práticos com JDBC, cobrindo tópicos como:

* Estabelecimento de conexão com banco de dados MySQL
* Execução de comandos SQL (SELECT, INSERT, UPDATE, DELETE) via Java
* Uso de Statement e/ou PreparedStatement
* Boas práticas de gerenciamento de conexões e recursos (open/close)

---

## 🛠️ Tecnologias utilizadas
* Java 21
* Maven (gerenciamento de dependências e build)
* MySQL Connector/J (com.mysql:mysql-connector-j)
* JUnit 4 (testes)
